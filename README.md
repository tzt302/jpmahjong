# JP MAHJONG

`jpmahjong.org` 的完整网页版日本立直麻将：玩家对战电脑雀士、和纸牌谱视觉、2.5D 牌桌。

## 1.2.0 功能

- 四人半庄与三人半庄；玩家风位、庄家、本场、供托与分数跨局延续
- 电脑雀士会按向听数与听牌数选择切牌，并处理立直、和牌、吃碰杠与拔北
- 不提供 AI 教练、实时提示或推荐切牌
- 按选定概念图重构的米白和纸牌桌、深靛牌墙、八角计分盘与四方名牌
- 手牌飞向牌河、AI 摸切、落桌回弹与轻量木质落牌声
- 四麻包含赤牌、食断、立直/一发/里宝牌、吃碰杠、抢杠、岭上、海底河底、振听、途中流局、流局罚符、双响、包牌、役满与符番点数结算
- 三麻采用主流网络三麻规则：108 张牌、移除二万至八万、35,000 点起始、无吃、拔北/抢北、三麻自摸损、双响及东南各三局
- 三麻补齐八张岭上牌、里宝牌、一发取消、加杠抢杠时序、立直后摸切/暗杠限制、九种九牌与四杠流局、流局满贯、包牌及南三终局/西入
- 末巡禁止立直、拔北及吃碰杠；多人同时鸣牌时按距放铳者的席位顺序决定优先级
- 暗杠即时翻杠宝牌，明杠/加杠在岭上打牌后翻牌；抢加杠时保留合法的一发判定
- 三麻结算使用中文役名，双响逐家展示，并列出荣和或自摸的实际支付点数
- 和牌结算页展示和了牌、总符番、逐项役种、表/里/赤宝牌、拔北与实际得点
- 自动理牌，摸入牌保留视觉间隔；赤五、立直横置牌、被鸣走牌与副露均保留状态
- 默认收缩的牌局侧栏
- 每日何切与 5 题入门闯关
- 浏览器本地保存答题进度
- 桌面与手机响应式布局

三麻线下规则存在地区差异；本站固定使用上述规则，不混用关西三麻的固定 30 符、无自摸损或祝仪规则。

## 本地运行

```powershell
npx serve .
```

然后访问终端显示的 HTTP 地址。项目使用 ES Modules，不能直接通过 `file://` 双击打开。

## 测试

```powershell
npm test
```
